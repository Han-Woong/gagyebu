카테고리 관리
카드는 종합 현황의 큰 카드(수입 / 저축투자 / 지출), 세부항목은 카드 안에 보이는 항목, 구분은 월별 입력 표에서 고르는 값입니다.
같은 세부항목에 여러 구분을 묶을 수 있습니다(예: 생활비 ← 반고정비 + 변동비). 구분 이름을 바꾸면 그 구분을 쓰는 입력 항목도 함께 바뀝니다.
차드햇반하우스 실행.bat으로 열면 같은 폴더의 차드햇반하우스_v01.xlsx를 처음에 자동으로 불러옵니다. 화면에서 고친 내용은 💾 저장을 눌러 ‘예’를 골라야 엑셀 파일에 반영됩니다. 저장할 때 하루 한 번 백업\차드햇반하우스_v01_YYYYMMDD.xlsx로 백업본도 남깁니다.
엑셀 시트: 카테고리(카드·세부항목·구분 정의), 입력(구분·항목명·항목설명·월예산·월별 실적, 월은 2026-11 형식 열), 설정, 사용법.
엑셀에서 고치고 저장한 뒤 이 화면으로 돌아오면 자동으로 반영됩니다(화면에 저장 안 한 변경이 있으면 제외). 엑셀에서 파일을 열어 둔 동안에는 화면에서 저장되지 않으니 저장할 땐 엑셀을 닫아 주세요. 화면에서 저장하면 파일이 다시 쓰여 엑셀에서 넣은 서식·수식은 값만 남습니다.
구글 시트로 쓰려면 오른쪽 위 ⚙에서 바꿉니다(비공개 시트 + 비밀키, 설정 방법은 구글시트_연결방법.txt).

데이터 연결

처음 설정은 같은 폴더의 구글시트_연결방법.txt를 보세요. URL과 비밀키는 이 기기의 브라우저에만 저장되고 HTML 파일에는 들어가지 않습니다.
